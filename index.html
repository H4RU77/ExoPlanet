Exo Planets

An exploratory data analysis of exoplanet observational data using scientific computing techniques.

Introduction

According to NASA, an exoplanet is any planet beyond our Solar System. Exoplanets orbit other stars, but there are also "rogue planets" which do not orbit any star. Some of these orbiting planets fall within the "habitable zone" of their host star, which is the distance from a star at which water on its liquid form could exist on the planet's surface.

Research Question

This research and analysis is guided by the following question regarding exoplanets:

Are there any exoplanets that fall within the habitable zone of their host star?

Dataset

For this project this Kaggle dataset was used. The relevant variables provided by these dataset were:

  • Name: name of the exoplanet.
  • Mass (MJ): mass of the exoplanet.
  • Radius (RJ): radius of the exoplanet.
  • Period (days): the period the exoplanet takes to make a full orbit around it's sun.
  • Semi-major axis (AU): is half of the longest diameter of an ellipse.
  • Temp (K): Temperature of the exoplanet.
  • Discovery method: method used to discover the exoplanet.
  • Disc. Year: Discovery year.
  • Distance (ly): Distance from earth in light years.
  • Host star mass (M☉): the star the exoplanet orbits around.
The data was cleaned and analyzed with python's pandas and numpy libraries.

Methodology

This project follows an exploratory data analysis (EDA) approach using real exoplanet observational data. The dataset was downloaded directly from Kaggle and processed using Python scientific libraries. This work is intended as an exploratory data analysis (EDA) rather than a definitive classification of habitable exoplanets

The analysis workflow includes:

  • Data acquisition and inspection using pandas
  • Identification of missing values and data completeness
  • Filtering relevant physical parameters related to habitability
  • Exploratory visualization of orbital and stellar properties

Due to the large number of missing values in several columns, the analysis focuses on exoplanets with available measurements of semi-major axis and temperature, which are key parameters for estimating habitability.

Data Cleaning & Limitations

The dataset contains a significant number of missing values, particularly in planetary temperature and orbital parameters.

To ensure meaningful analysis, rows with missing values in the following variables were removed:

  • Semi-major axis (AU)
  • Planetary temperature (K)

As a result, the analysis represents a subset of known exoplanets and should be interpreted as exploratory rather than exhaustive.

Analysis

To address this research question we can visualize the characteristics that make exoplanets habitable using Python-based visualization libraries such as Matplotlib and Seaborn.

What is the relationship between orbital distance and temperature?

Relevant variables:

  • Semi-major axis
  • Host star temperature
  • Radius

As a first step toward identifying potentially habitable exoplanets, we analyze the relationship between the semi-major axis of an exoplanet and its estimated temperature.

The semi-major axis represents the average distance between the planet and its host star, while temperature serves as a proxy for the energy received by the planet.

A random sample of 200 exoplanets was selected to improve visualization clarity and reduce overcrowding in the scatter plot.

To estimate whether a planet might be habitable we can use the semimajor axis of the planet―the distance from the center of the elliptical orbit of the planet to the farthest point on the perimeter of the orbit―and the host star's temperature. With these two variables we can use the concept of the habitable zone (HZ). The HZ is the range of distances from a star where a planet could have liquid water on its surface, given sufficient atmospheric pressure.

Toward Habitability Estimation

To estimate whether an exoplanet lies within the habitable zone of its host star, stellar luminosity must be calculated.

Stellar luminosity depends on the effective temperature of the star and its radius, according to the Stefan–Boltzmann law:

L = 4πR²σT⁴

Future steps of this project will incorporate stellar luminosity to estimate habitable zone boundaries and classify exoplanets accordingly.

Scientific Context

This project is inspired by current research in exoplanet science, where computational methods and large astronomical datasets are essential for identifying trends and guiding future observations.

While this study does not confirm habitability, it demonstrates how scientific programming and data analysis can be used to explore astrophysical questions using real observational data.
