## ExoPlanet

ExoPlanet is a conceptual project focused on exoplanet science and habitability, combining scientific computing, exploratory data analysis, and visual communication.
The project is designed for educational outreach and science communication, while maintaining a research-oriented structure and reproducible analysis workflow.

### Motivation
The project is motivated by an interest in exoplanet habitability, planetary systems, and the use of data-driven approaches to explore astrophysical concepts using real observational datasets.

### Research Question
Are there any exoplanets that fall within the habitable zone of their host star?

This question guides an exploratory analysis of orbital and physical parameters commonly associated with planetary habitability.

### Project Scope
This work follows an exploratory data analysis (EDA) approach and does not aim to confirm habitability.
Instead, it demonstrates how scientific programming and data analysis techniques can be applied to real exoplanet data to identify trends and relationships.

### Features
- Exploratory analysis of real exoplanet observational data
- Conceptual and interactive visualizations of planetary parameters
- Web-based presentation for science communication
- Reproducible analysis using Jupyter Notebooks

### Dataset
he project uses a publicly available exoplanet dataset from Kaggle, which includes physical and orbital parameters such as:
-Planet mass and radius
-Orbital period and semi-major axis
-Planetary temperature
-Host star properties
-Discovery method and year

### Technologies
-Python (pandas, NumPy, Matplotlib, Seaborn)
-Jupyter Notebooks / Google Colab
-HTML & CSS for project deployment and visualization

### Reproducibility
All data cleaning, processing, and analysis steps are documented and reproducible through the provided Jupyter Notebook.
The notebook can be viewed statically or executed interactively via Google Colab.

### Future Work

-Incorporate stellar properties to refine habitability estimation
-Explore the relationship between host star size and potential habitability
