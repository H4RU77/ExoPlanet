## ExoPlanet

Conceptual project focused on exoplanet science and habitability,
aimed at science communication and educational outreach.

### Motivation
Interest in exoplanet habitability, planetary systems, and data-driven
exploration of astrophysical concepts.

### Research Question
Are there any exoplanets that fall within the habitable zone of their host star?

### Features
- Conceptual visualization of exoplanet-related information
- Interactive data visualizations
- Real exoplanet dataset

### Technologies
HTML, CSS, Python

### Future Work
- Continue with the analysis in the rate of exoplanets that are in the habitable zone and whether the size of the host star is relevant in whether or not an exoplanet is habitable.
